## 🚀 COMMENT UTILISER

### 1. Lancer le serveur:
```powershell
python manage.py runserver
```

### 2. Se connecter à l'admin:
```
http://127.0.0.1:8000/admin/
```

### 3. Accéder au rapport:
- Dans le dashboard, cliquez sur le **bouton VERT 📊** d'un sondage
- OU depuis la page Résultats → "Rapport Statistique Professionnel"

### 4. Visualiser l'aperçu:
- Scrollez pour tout voir
- Vérifiez les tableaux
- Vérifiez les graphiques
- Vérifiez la mise en page

### 5. Télécharger:
- Cliquez sur "📄 Télécharger en PDF" (bouton rouge en haut)
- Le PDF se génère automatiquement
- Téléchargement dans votre dossier "Téléchargements"
